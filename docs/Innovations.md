# Les innovations de Carsy

Ce document recense toutes les innovations qui différencient Carsy des autres applications de mobilité.

---

# Innovation n°1 : Les trois modes de transport

## Description

Carsy ne propose pas uniquement un trajet classique.

L'utilisateur peut choisir entre trois modes de déplacement selon sa situation.

### 🚖 Mode Taxi

Un chauffeur emmène un ou plusieurs passagers d'un point A à un point B.

### 🚐 Mode Itinéraire

Un chauffeur crée un itinéraire avec plusieurs arrêts.

Des voyageurs différents peuvent monter ou descendre tout au long du trajet.

Le prix est partagé entre les passagers, ce qui rend le trajet plus économique.

### 🏛️ Mode Tourisme

Un chauffeur fait découvrir une ville ou des lieux d'intérêt aux visiteurs.

---

# Innovation n°2 : Assistant intelligent pour les chauffeurs

Carsy analyse le profil du chauffeur afin de lui recommander les trajets les plus adaptés.

Les recommandations prennent notamment en compte :

- les langues parlées ;
- le type de véhicule ;
- les disponibilités ;
- les préférences du chauffeur.

---

# Innovation n°3 : Notifications intelligentes

Les utilisateurs peuvent enregistrer leurs lieux favoris.

Si un chauffeur propose un trajet desservant un de ces lieux, Carsy peut envoyer une notification automatique au passager.

Exemple :

"Un chauffeur part dans 5 minutes et dessert le Champ-de-Mars."

---

# Innovation n°4 : Badges Chauffeurs

Les chauffeurs peuvent obtenir différents badges mettant en avant leurs compétences.

Exemples :

- Guide touristique
- Anglais
- Van
- Gros bagages
- Chauffeur expérimenté
